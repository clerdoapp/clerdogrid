# Changelog

## Unreleased

- **Cloud build for grid.clerdo.app:** sign in with a Clerdo account, save workbooks to the cloud with autosave, open them anywhere, version history with restore, share links, and a choice of version when a workbook was changed somewhere else. Workbooks saved by the first Grid web app open here. The desktop and offline web apps are unchanged. Build with `npm run build:cloud`; backend in `server/`.

## 0.6.0 — 2026-11-11

- **Page layout and printing:** page setup, headers and footers, print area and titles, page breaks, page break preview, page layout view, print preview and ClerdoGrid's own PDF writer with embedded fonts.
- **PivotTables:** live PivotTables saved with their data cache, field list, every summary and show-values-as option, calculated fields and items, grouping, PivotCharts, slicers and timelines, GETPIVOTDATA. GROUPBY and PIVOTBY take several aggregations.
- **Outline:** level and +/- buttons, Auto Outline, Subtotal and Consolidate.
- **Charts:** 66 types including stock, surface, 3D and filled map charts; trendlines, error bars and every chart element; chart sheets; sparklines. Newer chart kinds are saved in the extended chart format.
- **Files:** open and save .ods, .xls and .xlsb; open Excel 95 and older workbooks; password-protected files; text import wizard; export to web page, XML and JSON; Get Data with Refresh.
- **Working together:** live sessions with codes or QR, cursors and follow, share links.
- **Version history, view tools and Options:** versions, focus cell, navigation pane, full screen, split panes, sheet views, custom views, second window, workbook protection, manual calculation, R1C1, 1904 dates, error checking.
- **Formulas:** full regular expressions, forecasting, Flash Fill with preview, regions for numbers and dates, internet functions you can turn on, trim-range operators.
- **19 interface languages** with right-to-left for Arabic and Hebrew, and right-to-left sheets drawn for real.
- **Command-line tool and MCP server**, About window and contributors list.
