# Installing on macOS

Download `clerdogrid-<version>-mac-universal.dmg`, open it and drag **ClerdoGrid** to **Applications**. One file runs on both Apple-chip and Intel Macs.

The builds aren't code-signed yet. The first time, right-click the app, choose **Open**, then **Open** again. After that it opens normally.

To make ClerdoGrid open `.xlsx` files by default: select an `.xlsx` file in Finder, choose **File › Get Info**, pick ClerdoGrid under **Open with**, then **Change All…**.
