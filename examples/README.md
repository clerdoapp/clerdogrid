# Examples

Sample workbooks made by [`scripts/examples.ts`](../scripts/examples.ts) with ClerdoGrid's own code (`npm run examples`). Open any of them in ClerdoGrid, or in another spreadsheet app.

| File | What it shows |
|---|---|
| [`formula-tour.xlsx`](formula-tour.xlsx) | Dynamic arrays (`SORT`, `UNIQUE`, `FILTER`, `GROUPBY`, `SCAN`), `XLOOKUP`, `LET` and `LAMBDA` |
| [`sales-data.xlsx`](sales-data.xlsx) | 500 rows to sort, filter, chart and summarise, with a `PIVOTBY` summary sheet |
| [`sales.xlsx`](sales.xlsx) | A monthly sales report with totals, shares and a line chart |
| [`budget.xlsx`](budget.xlsx) | A monthly budget with planned, actual and difference columns |
| [`invoice.xlsx`](invoice.xlsx) | An invoice with line totals, tax and a grand total |
| [`loan.xlsx`](loan.xlsx) | A loan calculator built on `PMT`, with a payment schedule |
| [`expenses.xlsx`](expenses.xlsx) | An expense report |
| [`grades.xlsx`](grades.xlsx) | A grade book with averages and letter grades |
| [`attendance.xlsx`](attendance.xlsx) | An attendance sheet |
| [`todo.xlsx`](todo.xlsx) | A task tracker |
